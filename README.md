# 郭浩田 · 电气工程项目作品集

**Haotian Guo | Electrical Engineering Portfolio**

河南理工大学电气工程及其自动化本科，悉尼大学电气工程硕士在读。关注电气运维、数据中心基础设施供配电、设备运行与故障分析。

项目覆盖井下供配电设计、三相电路与故障分析、电力系统动态稳定性、低压配电网全年仿真、光伏及风电实验，以及实习中的 PCB 设计和工程交付。通过手算、建模、测量和数据分析，解释从正常运行到故障、扰动及控制后的设备与系统表现。
